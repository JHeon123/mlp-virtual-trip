# 🌏 가상 여행 서비스 (Virtual Trip)

> AI 이미지 기반 가상 여행 리뷰 플랫폼  
> 여행은 가고 싶지만 시간이 없거나 실제 여행이 부담스러운 사람들을 위한 서비스

<br>

## 📌 프로젝트 소개

등록된 여행지에 가상 여행 리뷰를 남기고, AI로 생성한 이미지를 리뷰에 첨부할 수 있는 플랫폼입니다.  
실제로 방문하지 않아도 이미지 2장과 프롬프트를 입력하면 AI가 여행지 분위기의 이미지를 생성해줍니다.

- **기간:** 2025.11 - 2025.12 (약 1개월)
- **인원:** 4명 (팀장: 이지헌)
- **GitHub:** https://github.com/JHeon123/mlp-virtual-trip

<br>

## 🔥 트러블슈팅

### 1. 이미지 2장 + 프롬프트로 이미지 생성 불가 문제

**문제**  
사용자가 입력한 이미지 2장과 텍스트 프롬프트를 OpenAI API에 한 번에 전달해서 이미지를 생성하려 했으나 불가능했음

**원인**  
이미지 2개 + 프롬프트를 입력받아 이미지를 직접 반환하는 OpenAI 모델이 존재하지 않음

**해결**  
2단계 파이프라인으로 분리
1. 이미지 2장 + 프롬프트 → **GPT-4o**에 전달 → 이미지 생성용 상세 프롬프트 반환
2. 반환된 프롬프트 → **DALL-E 3**에 전달 → 최종 이미지 생성

사용자는 버튼 한 번으로 두 단계가 순차 실행되어 결과 이미지를 받을 수 있음

---

### 2. 이미지 생성 중 페이지 로딩 block 문제

**문제**  
이미지 생성 버튼 클릭 시 생성 완료까지 페이지가 로딩 상태에 빠짐

**원인**  
동기 처리로 이미지 생성이 완료될 때까지 서버 스레드가 block됨

**해결**  
- `@Async` + `@EnableAsync`를 통해 이미지 생성 작업을 별도 스레드에 위임
- 프론트에서 **폴링(Polling)** 방식으로 주기적으로 생성 상태를 체크
- 완료되면 생성된 이미지를 화면에 표시

**결과**  
사용자는 버튼 클릭 후 페이지 로딩 없이 다른 작업 가능, 이미지 완성 시 자동 노출

---

### 3. 공공데이터 관광지 데이터 전처리

**문제**  
주어진 관광지 데이터를 그대로 키워드 검색 API에 사용하면 검색 실패 케이스 다수 발생

**원인**  
- `강릉 허균?허난설헌 기념공원` 처럼 특수문자 포함 데이터 존재
- 관광지명 앞에 지역명이 붙어 있어 API 검색 결과 불일치

**해결**  
1. 특수문자 제거
2. 공백 기준으로 split → 0번 인덱스(지역명) 분리
3. 1번 인덱스부터 키워드로 검색 API 호출
4. 응답 데이터의 주소에 지역명이 포함된 경우에만 DB에 저장

**결과**  
관광지 데이터 정상 수집 및 DB 적재 완료
